What is MC4JEditor?

A packaging environment for Minecraft Legacy projects.

MC4JEditor is a packaging tool developed as part of the Project MC4J ecosystem. Its purpose is to simplify the process of preparing Minecraft Legacy Console Edition projects for distribution within the MC4J environment.


The editor collects project source files and packages them into a compressed .mc4j archive, while keeping launcher-related files and compiled binaries separately accessible.


MC4JEditor is distributed as a standalone Windows executable. No Python installation is required to run it.


MC4JEditor does not provide Minecraft Legacy source code or compiled game binaries. Users must independently obtain the project files they intend to package.

Features

Tools designed to make preparing and packaging Minecraft Legacy projects more convenient.

.mc4j Packaging

Collect project source files and bundle them into a compressed .mc4j archive.

Package Metadata

Configure project names, descriptions and version information for each package.

Auxiliary Files

Include optional icons, main scripts and other launcher-related resources.

Extension Integration

Prepare MC4JLauncher extensions and preserve their directory structure.

Binary Organization

Keep compiled x64 game binaries alongside the generated package.

Package Validation

Validate required metadata and file paths before creating the final package.

How Packaging Works

Prepare your project and generate a structured distribution package.

01. Load Your Project

Open MC4JEditor and load your Minecraft Legacy project from the Home page.

02. Configure Metadata

Set the package name, description and version in the Packaging interface.

03. Select Auxiliary Files

Optionally configure your package icon, main.py entry-point script and extensions folder.

04. Choose the Destination

Select where the final .mc4j archive and accompanying files will be saved.

05. Create Your Package

Run the packaging process. MC4JEditor validates the configuration and generates the final distribution structure.

Package Structure

A generated MC4J distribution keeps source archives, metadata, extensions and compiled binaries organized.

The .mc4j archive contains the collected project source files. Other resources remain alongside the archive for MC4JLauncher to access.
