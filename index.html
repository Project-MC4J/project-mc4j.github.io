About Project MC4J

Project MC4J is an independent proprietary software ecosystem focused on tools and utilities for Minecraft Legacy Console Edition. Its software is distributed as executable releases; source code is not publicly available. Our goal is to provide a flexible environment for managing installations, creating projects and extending the Minecraft Legacy experience.
